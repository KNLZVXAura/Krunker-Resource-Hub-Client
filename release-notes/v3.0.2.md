## New
- **Windows MSI installer**: every release now also has a `.msi` installer next to the `.exe` Setup, built by GitHub Actions. It asks for per-user or all-users install and the folder, creates the desktop and Start menu shortcuts and removes cleanly from Apps & features. The in-app updater keeps using the `.exe` Setup.
- **Connection log**: when the game socket closes or a Krunker connection fails, the reason (close code, host, network error such as `ERR_NAME_NOT_RESOLVED`) is written to the log, so a "Lost Connection" screen can be traced. Use Copy report / the log in the dashboard and send it with the problem.
- **Proxy** (Settings > Performance > Proxy, also in the dashboard under Client Settings): send all traffic of the client through a SOCKS5, SOCKS4, HTTP or HTTPS proxy, with an optional login. Servers then see the proxy's IP address. It is a proxy, not a VPN: only this client is affected, it usually adds ping, and the proxy owner can see the traffic. The password is saved encrypted and never shown again. Needs a restart. Extra Performance Tweaks no longer adds `no-proxy-server` when a proxy is set.

## Changes
- **Quick Sell by Rarity** is no longer built in (and its switch is gone). A copy you installed yourself in the scripts folder keeps working.
- **Kill Streak** is the original script again, as it was written. It reads the kill feed with your name `You`. Switching it off needs a page reload.

## Fixes
- Game stuck on the loading spinner and then "Lost Connection" (code 1005) since 3.0.1 when a built-in script is switched on and the same script is also in the scripts folder (copies from the old "Example Userscripts" button): both copies ran, and Krunker Reconnector wrapped `WebSocket` twice, which made every game message fail with "Cannot redefine property: data". A script that is already running as a built-in (or the other way round) is now skipped, with a line in the log.
- Game stuck on the loading spinner and then "Lost Connection" (code 1005): the game socket tap is now invisible to the game (it no longer replaces `WebSocket` with a differently named subclass), and Extra Performance Tweaks no longer switches off Chromium's background tasks (`disable-best-effort-tasks`), which could stall loading on slow computers.
- The open issue count (Dashboard) always failed with status 422 in the log: the repository was renamed and GitHub search does not follow the old name. It now looks the repository up by its id.
- Userscripts and built-in scripts no longer run on `about:blank` pages (the parked KRH website window), which filled the log with "#uiBase not found" warnings.
- Lint errors in `packs.ts` fixed (they would have blocked commits through the pre-commit hook).
- The client now points to the new repository address (KNLZVXAura/Krunker-Resource-Hub-Client) for updates, links and the issue count.
