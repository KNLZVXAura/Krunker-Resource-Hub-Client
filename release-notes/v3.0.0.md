# KRH Client 3.0.0

## Fixed
- **Matchmaker Chaos Snipers and Bighead FFA filters** found the wrong lobbies (they matched Carrier and All or Nothing). They now find those modes
- **Motion blur lost the Saturation / Hue colours** while it was active, because the blur copy did not use the game's colour filter. It does now.
- **Swapper and theme settings named the wrong folder** (`swap/` instead of `swapper/`)

## Added
- **Server List Filter** (Settings > Server List): hides the servers whose map name contains one of your words from Krunker's server browser. Words are separated by commas; the default list is `infect, trade, trading, fun-parkour`. The toggle and the words apply the next time the server list loads, no restart. This is j4k0xb's Krunker Serverlist Filter, fixed: the old userscript replaced `fetch` and handed back the original response with a patched `json()`, and the game stopped loading since 2023. Here the answer is read from a copy and only replaced by a new, complete response when a server is actually hidden; any problem returns the untouched list. A game whose map name cannot be read is never hidden. Settings that the old script's README told you to edit in the file are now these two settings.
- **Separate Game Loop (Experimental)** (Settings > Experiments, off by default): an idea by KNLZVX. The game normally reads inputs, updates and draws once per screen frame, which adds up to 16 ms of delay on a 60 Hz screen; uncapped FPS works around it but makes the CPU and GPU work for frames nobody sees. With this on, the game's frame also runs on a timer between screen frames (**Game Loop Interval**, 4 to 33 ms, default 8), with the drawing calls of those extra runs skipped, so only one run per screen frame draws. Limits: WebGL only; the JavaScript side of rendering still runs on the extra runs; a picture the game draws only once (for example a shadow map) can be swallowed, so a missing shadow or reflection is possible; if the game throws too often in the extra runs the loop turns itself off. Switching it off at any time hands the game back to the browser's normal frame loop.
- **Tampermonkey scripts run as they are**: userscripts now understand `unsafeWindow`, `GM_setClipboard`, `@match` / `@include` / `@exclude` (www.krunker.io counts as krunker.io) and `@require` for the bundled msgpack-lite 0.1.26. `load` listeners registered after the page finished loading fire at once, like `DOMContentLoaded` already did.
- **Two more example userscripts** (Settings > Userscripts > Install), included unmodified: **Krunker Reconnector** by Swat (starts your private game again after "Server limit reached") and **Quick Krunker Docs Integration** by KNLZVX (the Quick KrunkScript docs in the Editor and the scripting screen). They start switched off.
- **Stat Counters** (Settings > Appearance, replaces the Nuke Counter): show nukes, kills, wins, headshots, wallbangs, melee, assists, thrown kills, sprays, crouches and K/D in the game. Kills, headshots, wallbangs, melee and thrown kills and K/D update live while you play, the rest when the match ends. Each stat has an optional goal, **Session Gain** shows how much a counter grew since the client started, and the layout is Stacked (one box) or Separate (each counter placed on its own with the **Move** button). Your old Nuke Counter setup carries over
- **Game Brightness** (Settings > World): dims or brightens the 3D game view from 20% to 150% without touching the HUD, nametags or menus
- **High-Performance GPU** (Settings > System, on by default): laptops with two GPUs run the client on the dedicated one. Can be switched off
- **Matchmaker updates**: new maps and gamemodes now appear in the matchmaker automatically, without waiting for a client update. With no gamemodes picked, the search skips Parkour, Raid and event lobbies. Picking only maps finds any mode on those maps. The ranked queue map list uses the same live list
- **The resource swapper is always on**: any file already in your swapper folder loads, and changes apply without a restart. Files in the wrong folder (a loose `main_custom.css`, or a `swapper` folder inside the swapper folder) show a warning in Settings > Swapper with a **Move It** button that fixes them. Swapper packs still work as before
- **CSS themes apply right away**: a theme starts as soon as you pick it and updates live while you edit its file. Themes inside a subfolder (like an extracted zip) and files saved as `.css.txt` now show up in the list
- **Links to `community.krunker.io`** now open in a client tab instead of your browser
- **Live Data** (Dashboard > Live Data): look up a player (stats, K/D, accuracy, nukes), a clan (roster with 7 day score), Turf Wars (who holds each map and the top 5 clans), the top 100 leaderboards for players and clans, and the item **Market** with a 30 day price analysis (average sale price, trend, and whether the lowest ask looks cheap or overpriced). The data comes from Krunker's public game API, which the [krapio](https://nulldev.github.io/krapio/) project documents (MIT, NullDev). No login is needed, nothing is sent except what you type, and replies are cached for a minute. Krunker does not document this API, so it can change without notice. Skins show as index numbers because the API does not name them
- **My Inventory keeps its place**: after a quicksell, listing or destroy Krunker used to throw the inventory back to the top and stop loading more pages; the view now stays where it was and refills
- **Ranked Match Sound Volume** (Settings > Matchmaker > Ranked): a volume slider for the sound that plays when a ranked match is found, also used by the preview button
- **macOS: the DMG installer opens a branded window** with the app and the Applications folder, ready to drag (built on GitHub Actions; the Mac build is still not notarized without Apple signing secrets)
- **Open Krunker Social (Ctrl+S) and Open Krunker Editor (Ctrl+E)**: open `krunker.io/social.html` and `krunker.io/editor.html` in a tab, or bring the tab forward when it is already open. They work from the game and from any Krunker tab, and can be changed in Settings > Hotkeys
- **Kill Streak** (example userscript): a white +N pop-up for every kill in a row, a small "Streak: N" label while the streak is active, and a nuke icon at 25, 50, 75 kills. The streak resets when you die (including falling off the map or suicide), and when the game or map changes. It only shows while you are really playing. Install it from Settings > Userscripts > Example Userscripts, then switch it on in the list. Switching it off works live, no reload needed.

## Changes
- The dashboard is English only. The real-time chat translator is separate and stays.
- Settings > Userscripts > Example Userscripts now adds five scripts (Class Roulette, Quick Sell by Rarity, Krunker Reconnector, Quick Krunker Docs Integration, Kill Streak). They start switched off, and existing files are never replaced.


## Performance
- Krunker's web3 and Twitter widget scripts are blocked, so there is less to load
- Windows: the client no longer starts an extra GPU process after launch to collect DirectX 12 information
