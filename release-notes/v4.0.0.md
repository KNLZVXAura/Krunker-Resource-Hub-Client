# Krunker Resource Hub Client v4.0.0
## New
- **Network HUD**: press `Ctrl+Alt+H` (changeable in Settings > Extras, together with the screen corner and "show at start") to see your ping, average, jitter, packet loss and a graph of the last 60 seconds. The numbers come from the TCP measurement the client already makes (`game-server-ping`); nothing is sent to the game. When your average ping is 70 ms or higher, the HUD tells you if another region measures clearly faster (at least 25 ms and 40% lower) than the region of your current game, read from the game id prefix such as `FRA:`. It only shows numbers and never switches region for you.
- **Full backup and restore** (Dashboard > Maintenance): one JSON file with your client settings, userscripts and their preferences, custom CSS, the built-in script preferences and your statistics. Saved accounts and the resource swapper folder are not included. Restore checks every file name (no `..`, only `.js`, `.css`, `.json`, `.txt`, `.md`, size limits), asks for confirmation and restarts the client. Files with the same name are overwritten, nothing is deleted. Userscripts run inside the game, so only restore backups you made yourself.
- **Statistics** (`Ctrl+Alt+K`): K/D per class, K/D per map and a bar chart of your kills in the last 7 days. Older statistics keep working, the new columns just start empty. The panel now lists your last 10 sessions (date and time, K/D, play time, matches, most played map) with a K/D under each day of the 7-day chart, and an **Export CSV** button saves every saved session to a file you choose, ready for a spreadsheet. **When you play best** shows K/D and kills per hour by part of the day and by weekday (counted where a session started) once there are enough sessions to compare. There is no headshot percentage because the client has no reliable headshot signal.
- **Kill Streak settings** (script v1.1.0, Settings > Userscripts): 11 options for the position, size, colour and duration of the pop-up, a nuke every N kills (0 = off), nuke icon, streak label, a sound per kill with volume, a hint when the kill feed is not switched on, and a debug mode. Your name is matched automatically (`You` plus your `krunker_username`, not case-sensitive).
- **Hotkey conflict warnings**: every key field in Settings (and the key buttons in Controls) now warns in orange when the combination is already used by another feature, including the fixed keys such as the Spotify keys, the tab keys and the quick-login keys. Before, two features on the same key meant one of them silently did nothing.
- **Script Health** (Settings > Userscripts, in the game and in the dashboard): for every script, whether it is running, switched off, failed (with the error), skipped because the same script already runs, or not meant for this page, how long it took to start, and hints from reading its code (wraps WebSocket, uses eval, clears localStorage, runs something every few milliseconds, has no unload function). A warning appears when more than one running script wraps WebSocket, the cause of the "Lost Connection" problem. The hints are guesses from the code, not proof. **Find The Problem Script** (same page) helps when the game freezes or shows "Lost Connection": it switches your scripts off in halves, you reload the game and answer "still happens" or "it is gone" after each step, and after about 3 to 5 tests it names the script that causes it. Your other scripts are switched back on, the one found stays off, and a hunt can be cancelled at any time. Scripts you changed in the last 14 days are searched first. When the game connection drops three times within 10 minutes, each time soon after it opened (the typical sign of a broken script), the client asks once whether it should start this search (switch it off with **Offer To Look For A Broken Script**; at most once for each start of the client). **Problem Report** > **Copy Report** (also in Dashboard > Diagnostics) now includes how every script is doing, the latest connection events from the log, the state of a script search and the backups, next to the versions, your PC and the end of the log; e-mail addresses and tokens stay hidden.
- **Auto Profiles** (Settings > Extras): rules that switch settings by themselves while you play. A rule can name a class, a game mode, a map (parts of the name are enough), a server region (FRA, SV, TOK ... from the game id) and a game type (custom or public; this only works when the game reports it, otherwise such a rule never matches) and applies a saved Sensitivity preset, a saved FOV preset, a crosshair and extra CSS files. The most specific matching rule wins, and a rule without class, mode or map is the default. A rule is applied after the same match was seen twice in a row, never in the menu. The crosshair and the extra CSS only last while the rule is active; CSS files you switched on yourself are never touched. Sensitivity and FOV stay at the last preset when no rule fits, so add a default rule to go back to your normal values. **Share** on a rule copies a share code with the rule and the presets it uses; importing a code (Settings > Extras > Share Codes) adds the rule and the presets to yours. There is no casual versus ranked trigger because the client has no reliable way to tell them apart.
- **Ping History** (Settings > Extras): the client keeps the average ping of each region for every hour of the day, on your computer only, and shows which region is usually fastest for you around the current hour. A sample is added each time the client measures the region pings (when the matchmaker is on, and when you search), at most one per region every 5 minutes, and old samples fade out. When the Network HUD is on and the live numbers show nothing better, it also tells you if the history says another region is usually clearly faster around this hour (at least 25 ms and 40% lower, with enough samples); it only suggests and never switches region.
- **Automatic backups** (Settings > Extras): right before an update is installed (on by default) and also on a schedule (every day or every week, weekly by default), the client saves your settings, userscripts, custom CSS and statistics into `backups` in the KRH Client folder and keeps the newest 3 of each kind. **Copy Backups To A Folder** also copies every automatic backup into a folder you choose (for example a OneDrive or Dropbox folder; the newest 6 copies are kept there, nothing is uploaded by the client, and only you can change the folder, not a backup you restore). The same group lists the saved backups with a **Restore** button (it asks first, replaces files with the same name and restarts the client). Not done in safe mode.
- **Daily goal, break reminder and session comparison** (Settings > Extras > Session Stats): set a kills-per-day goal and a message shows when you reach it, set a number of minutes and a message suggests a break after that much play without a pause of 5 minutes or more (and again after each further interval). The summary notification when you leave the game now compares the session with your earlier ones (K/D and kills per hour against your average) once there are at least 3 earlier sessions and 30 minutes of play.
- **FPS by map and class** (Settings > Extras, on by default): while you are in a match the client measures FPS in windows of 5 seconds with a very light frame counter (nothing runs in the menu or while the page is hidden) and shows the average FPS and the 1% low for each map and each class, heaviest first. The data stays on your computer and fades out over time; switch it off in the same group. Each map in the list has a **Create rule** button that adds an Auto Profiles rule for that map with the CSS files you typed above the list (a lighter look for example).
- **Settings history with Undo** (Settings > Extras): every time a settings category is saved, the value it had before is kept (changes within 15 seconds are merged into one), and a list of the recent changes has an **Undo** button per change. Undo asks first, puts the category back to how it was before that change (later changes in the same category are undone too) and restarts the client. Accounts, window positions and the pack and streamer switches are not covered.
- **Network Doctor** (Settings > Extras): one test of about 15 seconds that checks DNS for krunker.io, a few well-known servers (Cloudflare, Google) and the Krunker region servers, then says in plain words whether the problem is no internet, your DNS, your own unstable connection, the route to one region, or just distance to the servers. Nothing is kept, and **Copy Result** copies the answer as text. A region that does not answer ping is reported as such, because some block it.
- **Smarter crash recovery**: when the client did not close properly several times in a row and offers Safe Mode, the dialog now has two more choices when something recent can be blamed: **Undo Last Change** puts back the settings category that was changed last (within 3 days; not for the userscript and swapper folder settings), and **Switch Off Newest Script** switches off the userscript you edited most recently (within 14 days). Each starts the client normally afterwards, and the dialog says exactly what it would do.
- **Performance Changes** (Settings > Extras): the client adds up FPS per map and ping per region by week, and a few minutes after it starts a quiet notification says if something is clearly lower than last week (at least 15% and 10 FPS, or 25% and 15 ms, with enough measurements in both weeks); each set of findings is shown once. The same page lists the findings together with the settings changes of the last 7 days and the date of the last client update, as hints (a drop can also come from the game, drivers or other programs). Switch the notification off in the same group.
- **Ready To Play** (Settings > Extras): one check before a session that combines a short connection test (about 6 seconds), how your userscripts are doing, Safe Mode, a running script search, clear drops since last week and the settings that limit FPS (the same checks as Dashboard > Diagnostics > Performance Doctor), and ends with "Ready to play", "a few things are worth a look" or "needs fixing". It only reads and reports, and **Copy Result** copies it as text. Open the game first for a real answer about the scripts.
- **Replay Clips** (Settings > Extras): saved instant-replay clips are now named after what is in them (for example `Krunker_replay_..._Sandstorm_Hunter_7streak.mp4`, the streak only when it is 2 or more), and a gallery lists the newest 100 with date, size and length, with **Open**, **Folder**, **Rename** (renames the file) and **Delete** (asks first, then moves the clip to the recycle bin). Clips from before this version are listed too, without map and class.
- **Restore preview**: before a backup is restored (from the list or from a file), the confirmation shows what would change: the version and date of the backup (with a warning when it comes from a newer client), the settings groups and fields that differ from now, and how many files are new, would be replaced with different content, or are identical, with their names. Only names are shown, never the contents of a script.
- **Scripts changed outside the client** (Settings > Userscripts > Script Health): the client remembers every userscript and, at game start, compares the folder with what it saw last time. A script that was edited or replaced by another program, added to the folder or removed gives one quiet notification, and the list shows the number of lines added and removed, a few added lines and risky things that are new in the script (network requests, eval, WebSocket wrapping, clearing localStorage). The first start only learns the scripts that are there; edits made in the dashboard editor, added or deleted there, or restored from a backup are accepted silently. Built-in scripts are not covered.
- **Earlier versions** (Settings > Extras): lists up to 5 earlier releases from GitHub that have a Windows installer with a SHA-256 digest, and **Go Back** downloads the chosen one, checks the SHA-256, saves a backup of your settings first (even when the automatic backup is off), closes the client and runs the installer. The update prompt then skips the version you left but still offers newer ones. Only for the installed Windows version; the portable, Linux and macOS builds get a link to the releases page. GitHub allows 60 requests an hour per address, so the list can be unavailable for a while. Going back is not tested on every Windows setup: if the installer refuses, uninstall first and install the older version.
- **Session labels**: the statistics panel (`Ctrl+Alt+K`) has a **Label** picker (ranked, scrim, casual, practice, or one you type) that applies to the running session and stays for the next ones until you change it. A **By label** section shows K/D, kills per hour and the number of sessions per label, and the CSV export has a label column.
- **Best region marked in the matchmaker**: in Settings > Matchmaker, the region list marks the regions that are usually fastest for you around this hour with their typical ping, and a star on the best one, from the Ping History. It only marks: which regions are searched is still your choice.
- **Storage** (Settings > Extras): shows how much disk the client uses (logs, automatic backups, replay clips, the recordings folder, the web cache, its data files, userscripts, custom CSS and the swapper folder) and can clean old files it made itself: logs, automatic backups and replay clips older than 30, 90 or 180 days (the newest are always kept, the clips go to the recycle bin), and the web cache. Every cleaning asks first with the number of files and their size. Your scripts, CSS, swapper files and other recordings are never cleaned here.
- **Weekly summary** (Settings > Extras, on by default): on the first start of each week a quiet notification sums up last week (Monday to Sunday) from your statistics: play time, K/D compared with the week before, your best map (at least 20 kills and deaths on it) and clear FPS or ping drops. A week with less than 10 minutes of play gets nothing, and "Last Week" shows the summary on demand.
- **Play Log and K/D by ping** (Settings > Extras, on by default): while you are in a match the client takes a small sample every 10 seconds (map, class, the ping to the game server, the kills and deaths since the last sample), only then and only while the page is visible. It shows your time, kills and deaths per ping range (up to 40, 41-80, 81-120, 121-200, above 200 ms) and answers "do I play worse with a high ping?" by comparing up to 80 ms with above 80 ms once each side has at least 10 minutes, with the reminder that map, class and opponents matter too. It also lists your latest rounds with their average ping and FPS. Krunker plays matches one after the other in the same lobby with no signal between them, so a round is a stretch on one map (a new one starts when the map changes or after a 3 minute break), not exactly one match. Kills and deaths need the session statistics switched on.
- **Connection Journal** (Settings > Extras, same switch as the Play Log): notes every unexpected disconnect, every ping spike (at least 150 ms and 2.5 times the usual ping) and every stretch where the game server did not answer twice in a row, with time and region, shows a 7-day graph and the latest events, and **Copy For Provider** copies the last 14 days as plain text to show your internet provider or a server admin.
- **Logs page** (Dashboard > Logs): reads the client log of any saved day, filtered by topic (errors and warnings, connection, scripts, updates and backups) and by search text, shows the last 800 matching lines with e-mail addresses and tokens hidden, and can copy what it shows.

## Changes
- **Release notes are bundled** with the app: the "What's new" popup after an update now reads the notes of the installed version from inside the app, so it also works offline and no longer depends on the GitHub rate limit. GitHub is only asked when the notes are missing from the app.

## Notes
- **Windows**: the builds are not code-signed. On "Windows protected your PC" click **More info > Run anyway**. If the `.msi` does not install, right-click it > **Properties** > tick **Unblock** > **OK**; error 1603 / 1618: close other installers or restart Windows and uninstall an older KRH Client first. The `Setup.exe` and the Portable version work without MSI.
- **macOS**: there is no signed build; build the DMG yourself or with GitHub Actions (see the README).
