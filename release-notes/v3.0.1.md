## New

- **Built-in scripts**: Kill Streak, Class Roulette, Quick Sell by Rarity, Krunker Reconnector and Quick Krunker Docs Integration are now part of the client. Each has its own on/off switch in Settings > Userscripts, and in the dashboard under Settings > Userscripts. They work even when the scripts folder is switched off, they start switched off, and turning one off takes effect right away (no reload).
- **Kill Streak** (new): a white +N pop-up for every kill in a row, a small "Streak: N" label while a streak is active, and a nuke icon at 25, 50, 75 kills. The streak resets when you die (including falling off the map or suicide) and when the game or map changes. It only shows while you are really playing.

## Changes

- The "Example Userscripts" install button is gone. The scripts it added are built in now, so there is nothing to install. A copy that was installed earlier into the scripts folder stays there and keeps working as a normal script, so switch it off if you also use the built-in one.
- A script's own settings and its unload function are now picked up when the script sets `this.settings` and `this.unload`, with or without `return this`.

## Fixes

- Built-in scripts that did nothing after being switched on (the settings of Class Roulette and Quick Sell by Rarity were not shown, and switching a script off needed a reload) now work.
- Quick Krunker Docs Integration never ran: the map editor and the scripting window did not load userscripts at all. It now adds the Quick KS Docs links and tab there.
- Fixed the release build failing at "Install dependencies" on Windows, Linux and macOS (a broken lock file made `npm ci` stop before anything was built).
